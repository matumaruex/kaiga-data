# 第10群：候補31件の研究と画像検証の進行記録

作成日：2026-10-19。現時点の**試験登録は83作品／約100作品目標**。このファイルの「候補」は登録済み作品を意味しない。

## 研究対象

31候補を [data/candidates-batch-010.json](../data/candidates-batch-010.json) に記録。
- 恋愛の切望と待つこと：インドの《花を摘むヒロイン》(37881)、《恋人を慕うヒロイン》(37992)、《デシュヴァラティー・ラーギニー》(38017)。**恋い慕う**ことが、そのまま現代日本語の「未練＝過去の関係に執着」と同義ではない。
- 歴史を伴う懐かしさ：中国の伝・馬守真《蘭と岩》(48932)は**後世の人の明朝への郷愁**。朝鮮の《金剛山内山総図》(748432)は**訪れたい場所への憧れ**。どちらも絵の作者が故郷に戻りたいと思ったとは断定できない。
- 宗教と悲嘆：トリシャラー王妃の悲嘆(74983)、喪失を描くヨーロッパ作品(441352、437035、439553)などを比較。作者自身の喪失体験に還元しない。
- 異なる社会的立場：ホーマー《カーニバルの支度》(11116)は黒人コミュニティの文化の継続と人権後退を共に説明。ベリゼールの肖像(898196)は隠されていた奴隷少年の姿が修復によって再発見された経緯を含む。希望や好奇心という安易な分類で史実の暴力性を消さない。
- 近現代の優良な記憶・郷愁の作品も調査するが、著作権下にある可能性が高いものは公式PD旗を照合し画像公開不可なら保留にする。

## 検証基準

1. The Metropolitan Museum of Art公式作品ページに紐づくObject APIで作品ID・所蔵番号・題名・Painting分類・isPublicDomain=trueを確認。
2. 公式Object APIが返す当該作品の primaryImage JPEGを実取得し、JPEG形式・サイズ・SHA256を確認する。
3. 主タグ1〜2、補助0〜2は作者の言葉、作品の物語、専門家の研究を分けたうえで評価。数値合わせのため付与しない。
4. 一対の屏風、二幅対、長い絵巻は追加の画像と並びの確認が済むまで保留。
5. human visual_checked=false、interpretation_human_approved=falseを維持し、完成品として公開したとは主張しない。
