# 第10群：83 → 100作品、17登録・14保留（2026-10-19）

## 結果：目標100作品に到達（あくまで試験用）

- The Metropolitan Museum of Artの個別作品ページから**31候補を調査**し、現行公式Object APIで作品ID・題名・所蔵番号・作者・Painting分類（分類空欄の油彩作品には公式mediumに基づく例外）・`isPublicDomain`を再照合。
- うち**25/31件で公式情報とJPEG実取得が成功**。JPEGのバイト長・形式・SHA256を検証し、[公式API/画像検証結果](batch010-online-result.json)に残した。
- **17作品を追加試験登録、14作品を保留**。既存83＋17＝**100試験作品**。画像出典台帳は**101件**（登録100＋旧保留『Judith』1）。31候補の審査状態は[候補履歴](../data/candidates-batch-010.json)参照。
- 作品の感情を画家本人の個人的経験と誤認しないため、作者の制作意図の直接一次資料を検証していない作品は **`not_verified_for_this_work`** のままとした。画家の経歴、詩歌の題材、描かれた人物の感情、当時の社会的背景、後代の受容を分離。
- **画像の人間による最終視認、学術的な意味の人間承認、展示組版、公開前の法的確認はまだ行っていない**。作品が100点あることと「完成した公開用美術館」は別。展示体験は次の独立した段階。

## 保留14作品の内訳

**画像・公開権利などの条件不足（8件）**

- Met公式`isPublicDomain=false`： [堀井香坡《雷》](https://www.metmuseum.org/art/collection/search/871870)、[張大千《蓮》](https://www.metmuseum.org/art/collection/search/49802)、[Yeung Tong Lung《Evergreen Beauty》](https://www.metmuseum.org/art/collection/search/910299)、[張暁剛《緑の壁》](https://www.metmuseum.org/art/collection/search/924756)。
- [シーター・ラーム《モティジルのモスクと門》](https://www.metmuseum.org/art/collection/search/454429)：公式分類が`Codices`であり、絵画限定スキーマへ無理に入れない。
- [俵屋宗達《月に秋草図屏風》](https://www.metmuseum.org/art/collection/search/48923)：現行APIの作者表示と候補の「宗達工房」という帰属が一致せず、さらに屏風全体の画像順序が必要。
- [岩佐又兵衛《瀟湘八景》](https://www.metmuseum.org/art/collection/search/853201)：二幅対の掛幅。主画像は取得済みだが両画面の組と並びが未確認。
- [張瑞図《後赤壁賦図》](https://www.metmuseum.org/art/collection/search/48969)：長い巻物。主画像のJPEGは検証済みだが全場面の鑑賞には不十分。

**感情解釈が弱く、今回の作品群では登録を見送ったもの（6件）**

- [渡し舟を待つ](https://www.metmuseum.org/art/collection/search/36007)：待機している＝「期待」とはしない。
- [金剛山内山総図](https://www.metmuseum.org/art/collection/search/748432)：行ったことのない山への憧れと懐かしさを混同しない。代表画像が約42 KBで複数の関連画像あり。
- [ゴンドラの出発](https://www.metmuseum.org/art/collection/search/438130)：カーニバルの風俗画から「喜び」を断定しない。
- [エドワードとサラ・ラター](https://www.metmuseum.org/art/collection/search/11269)：画家ジョシュア・ジョンソンの歴史的重要性はあるが、肖像の子どもたちが希望を抱いている証拠にはならない。
- [鶏と葡萄](https://www.metmuseum.org/art/collection/search/40459)：鶏が人間的な未来への期待を抱いていると擬人化しすぎない。
- [荊冠のキリスト](https://www.metmuseum.org/art/collection/search/435580)：苦痛・犠牲と『喪失感』は同義ではない。
