# 絵画データの基本方針

作品データの正本は `data/artworks.json`、画像の記録は `data/image-sources.json`。作品数・完成状態は最新mainのデータと完成監査から確認する。

- 基礎事実、作者の発言・専門家の解釈・制作背景・画面観察・不確実性を区別して記録する。
- AI選定には主・補助感情の索引と作品固有の `curation.meaning_basis`・検索プロフィールを用いる。`summary_for_ai` などの廃止項目を復活させず、同文を不要に複製しない。
- 鑑賞者向けの `visitor_explanation` は選定用データとは別に扱い、作品別の公式・専門出典と照合する。
- 感情タグは作品の価値や鑑賞結果を証明するものではなく、自然な根拠が無ければ0件でもよい。
- データ登録・公開配信・権利確認を同じ完了状態だとみなさない。

実際の完成条件は [共通品質基準](artwork-completion-workflow-v2.md)、新規登録の手順は [追加ガイド](artwork-expansion-v2.md) が正本。古い件数・審査状態・設計過程は [以前の基本方針](history/data-policy-through-2026-11-10.md) に保存した。
