1. 最新mainとPR #3を取得し、`python3 scripts/complete_artwork.py check`でmainの保存済み版を確認する。このコマンドは別ブランチだけにある保留を数えない。

3. [登録手順](artwork-registration-v2.md)に沿って新監査でpreview、save、対象外作品の不変確認、既存テスト・CIを実施。合格した1作品を保存し、レビュー可能な差分をmainへ統合する。
4. 保存したIDと再開位置をこの文書またはリンク先で更新する。「合格した下書き」と「正式DBに保存済み」を区別し、ユーザーには全体の現在地を短く報告する。

既存解説の置換・新規作品登録・画像のバイト差は初期登録コマンドの対応範囲外。失敗を回避するために検査を外さない。`bijutsukan`の確認時点のmainはREADMEのみで、データ保存をサイト公開完了とは扱わない。
