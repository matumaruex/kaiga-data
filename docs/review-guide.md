# 作品レビューの参照先

現在の完成判定・別工程の実質監査は [作品の共通品質基準](artwork-completion-workflow-v2.md) に従う。新規登録の実行手順は [新規作品の追加手順](artwork-expansion-v2.md) を参照する。

初期登録時の `review.*` の細かな状態や人間承認の記述は、既存データの互換性と履歴のために保存するもので、完成済み作品を再び「未完成」とする追加の作業指示ではない。

以前のレビュー用チェックリスト・移行記録は [旧レビューガイド](history/review-guide-through-2026-11-10.md) に保存した。
