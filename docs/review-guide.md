# 作品の検証・レビュー手順（2026-10-20改訂）

> **現行方針：人間の美術史的精査・画像目視・解釈の最終承認を登録・展示の必須条件にしない。**
> 作者の言葉や美術館の原資料、公式作品情報、画像を根拠としてAIとプログラムが検証する。
> 人間による鑑賞体験の評価は任意であり、作品内容の事実認定を人間へ丸投げしない。

## A. 作品の登録・形式チェック（プログラム）

- [ ] `python3 scripts/validate_artworks.py` が成功
- [ ] 作品IDの重複なし・既知の感情タグ・主補助の区別と強度が整合
- [ ] 絵画分類、公式作品ID、原題、作者表記、制作年代を照合
- [ ] 作品自体のパブリックドメイン表示と画像の再利用条件を区別して確認
- [ ] 画像のURL、JPEG実取得、SHA256、登録IDの紐付けを検証
- [ ] **ハッシュ一致は画像の真正性や描かれた作品との一致を証明しない**。実際の画面との照合は別途行う

## B. 原資料と作品解釈のレビュー（AI）

- [ ] 作者の手紙・日記などの直接証言と、専門家・美術館の読解を混同しない
- [ ] `scholarly_interpretation.summary` は引用元が支持する**作品の解釈**を示す（単なる作品紹介で置き換えない）
- [ ] `creation_context` は制作時期、経緯、人物・時代状況などの**制作背景**を示す（確認できなければ推測で埋めない）
- [ ] 同じ文章が複数欄に入った作品は `ai_content_review_status=needs_revision` とし、個別の出典再調査対象にする
- [ ] URLがあるだけでは検証済みとしない。該当箇所が内容を裏付けるか実際に照合する
- [ ] 不確実性や異説を残し、根拠のない作者の心理・制作意図は断定しない
- [ ] AIが検証不能だった箇所は `pending` か `needs_revision` のまま残す。AIの再言い換えを独立した検証として扱わない

## C. 感情タグ・展示への接点（AI、鑑賞結果で誘導しない）

- [ ] 画面が暗いというだけで「悲しみ」、静かというだけで「安心」と決めない
- [ ] 「悲しみ／喪失感／寂しさ」「畏敬／不安」「慈しみ／愛情（主題）」を区別する
- [ ] 作者の研究熱心さや逸話だけで「好奇心」を付けない
- [ ] 感情は鑑賞者の入口であって作者本人の心理の証明ではない
- [ ] 主0〜2、補助0〜2。合うタグがなければ0件で構わない
- [ ] 本文・出典・感情タグ・AI選定用要約の整合を確認する
- [ ] 反対の読解や選定上の注意を保持し、登録数や感情数を均すための修正をしない

## D. 検証状態と展示への使用

- `review.ai_content_review_status`: `pending` / `verified` / `needs_revision`
- `review.source_evidence_review_status`: `pending` / `verified` / `needs_revision`
- `review.image_subject_match_status`: `pending` / `verified` / `needs_revision`
- `curation.search_profile.review_status`: `evidence_review_pending` / `evidence_reviewed` / `evidence_review_needs_revision`
- `review.curatorial_review_status`: `provisional` / `approved` / `needs_revision`。ここでの `approved` は**原資料と内容の検証状態**であり、人間の承認ではない。

**資料・AIレビューの `verified` は必ず実際の照合根拠に基づく。** 自動整合検査の合格だけでは `verified` にしない。
`curatorial_review_status=approved` は上記3つのレビューが `verified` の場合のみ使用可能。
試験展示では `provisional` の作品を利用してよいが、未検証の説明を確定した歴史的事実として見せない。
公開・再配布の権利条件は人間の最終目視の代わりに、権利の出典と許諾条件を確認して管理する。条件が不明なら保留する。
人間の最終承認フラグ `interpretation_human_approved` は廃止。古いバッチの「人間未承認」という記録は当時の作業履歴であり、現在の合格条件ではない。

### 2026-10-20時点の移行記録
- 登録済み300作品すべてに新方式の状態欄を付与。事実・タグ・画像URLは変更していない
- 同文146作品の `ai_content_review_status` は `needs_revision`、残り154作品は `pending`
- 出典の内容照合および画像と作品の内容照合は新方式で未完了として `pending` を保持
- 公式APIによる基本情報・PD表示・JPEGハッシュ検証の既存記録は保持。ただし解釈の正確性を保証するものではない

## F. 将来の鑑賞者向け解説に必要な資料の監査（現時点では解説本文を作らない）

- [ ] **登録全件**について同文の有無に関係なく、作者の言葉・専門家の作品解釈・制作背景・画面の具体的な見どころ・不確実性を分けて点検する
- [ ] それぞれの事実・解釈を支える個別の一次資料または信頼できる美術館研究の**該当箇所**を確認する。URLだけ・汎用的な作家紹介だけでは照合済みにしない
- [ ] 将来、鑑賞者が第一印象を持った後に読む**1種類の自然な解説文**を、作品固有の材料から書けるだけの具体性があるか評価する。資料不足なら不足点・追加調査先・保留理由を記録する
- [ ] `summary_for_ai`、感情タグ、適合理由を、鑑賞者向けの完成解説だと扱わない。感情的な反応を決めつけたり、予想外の感動を意図的に演出したりしない
- [ ] 今は鑑賞者向け本文の全件生成や、複数段階の詳細解説・作者伝・時代史ページの新設をしない。基礎資料を整えた後、異なる作品5〜10件で日本語約200〜350字を目安に試作・独立照合してから、文章制作の方針を判断する
- [ ] **形式的な全件監査**と**原資料を実際に開いて確認する内容監査**を別々に報告し、未実施の原資料照合を `verified` としない

この監査基準の目的・役割分離は [データの基本方針](data-policy.md#鑑賞者向け解説の制作準備2026-10-20追加) を参照。

## E. 展示体験の任意評価

「恋人と別れた」「ひとりぼっちに感じる」「昔の家に帰りたい」などの入力で、選定された作品と選定されなかった作品を比較する。
鑑賞者は自由な感想や満足度を伝えられるが、学術的な正誤判定や資料収集を要求しない。
1回の展示の成功体験を、将来の鑑賞者が必ず感じる結果として作品タグや選定規則に固定しない。

## 感情の強さ（維持）
- **3**：作品の構成や資料から比較的明確に結び付く
- **2**：作品の題材・構成から無理なく関連する
- **1**：具体的な接点はあるが弱い補助的関連

この数値は資料の確実性や作者の心理の強さではなく、鑑賞者の入力感情と作品との関連度を表す。
