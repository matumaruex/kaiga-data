# レビュー手順

## A. 自動チェック
- [ ] `python3 scripts/validate_artworks.py` が成功
- [ ] 作品IDの重複なし・存在する感情タグのみ
- [ ] 作品は絵画であり、APIのPDフラグを確認済み
- [ ] 画像URLを実際に開き正しい作品が表示される（現段階は未確認）

## B. 出典との照合
- [ ] 原題・作者・年代が出典と一致
- [ ] 作品自体の権利と画像の利用条件を区別している
- [ ] 作品の歴史的背景について根拠がある
- [ ] 伝聞・推測を確定した史実として書いていない

## C. 感情の選定品質
- [ ] 色が暗いだけで「悲しい」と決めつけていない
- [ ] 主感情・空気感・作品主題を混同していない
- [ ] 作者の探究心や面白い裏話だけで、鑑賞者の「好奇心」タグを付けていない
- [ ] 「悲しみ／喪失感／寂しさ」「畏敬／不安」「慈しみ／愛情（主題）」を区別している
- [ ] 適切な感情がないときに無理に主感情を設定せず、タグなし・補助のみも認めている
- [ ] 「なぜこの作品か」を説明できる
- [ ] ほかの解釈（反対の読み）が記載されている
- [ ] 特定の有名画家や似た作品に偏りすぎない
- [ ] 深刻な感情に無理に前向きな解釈を当てはめていない

## D. 実地テスト（作品数が増えてから）
テスト入力例：
- 「恋人と別れた。まだ好きで苦しい」
- 「誰かといてもひとりぼっちな感じがする」
- 「すべてがうまくいきそうで嬉しい」
- 「昔の家に帰りたい」
- 「特に理由はないけど、少し落ち着きたい」

各テストについて「合う」「微妙」「不適切」を記録し、**選ばれなかった作品**も含めて見直す。4作品しかない現段階では網羅性の評価はできない。

## 役割分担
- チャット：調査・仮タグ付け・一次検証・修正案
- 人間（2人）：鑑賞体験の評価・感情解釈の採否
- アプリ：独立したデザインで共通データを利用

**人間が未確認の作品は `review.interpretation_human_approved=false` のままにする。**

## E. 感情の強さ（2026-10-18追加）
- **3＝強い関連**：作品内容や資料に直接的な裏付けがある
- **2＝中程度**：主題や構成から無理なく読める
- **1＝弱い関連**：連想として可能だが、別の読み方も十分ある

1のタグだけを根拠に強く推薦しない。タグは**感情の客観的真実ではなく作品解釈の候補**。感情の重みも人間が鑑賞して見直す。
