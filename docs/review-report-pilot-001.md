## 作品別評価

### 1. Vincent van Gogh, The Bedroom（1889） / aic-28560
- **安心＝3**：作者は最初の『寝室』について休息を意図したと手紙に書いた。シカゴ所蔵はその第二版。
- **懐かしさ＝1／寂しさ＝1**：鑑賞者の連想としては可能だが、歴史的な意味としては確定できない。
- 出典：https://www.nortonsimon.org/exhibitions/2010-2019/vangoghbedroom
- シカゴ所蔵の第2版の年代確認：https://archive.artic.edu/van-gogh-bedrooms/timeline

### 2. Gustave Caillebotte, Paris Street; Rainy Day（1877） / aic-20684
- **孤独＝3**：美術館解説にある「都市での匿名性」「人物間の距離」を根拠とする。
- **不安＝1／好奇心＝1**：見る人の連想にとどまる。
- 出典：https://archive.artic.edu/500ways/artwork/20684?from=14591

### 3. Georges Seurat, A Sunday on La Grande Jatte — 1884（1884–86） / aic-27992
- **安心＝2／好奇心＝2**：公園での余暇と点描技法から結びつける。
- **孤独＝1**：人が集まっていても交流が希薄に見えるという読み。
- 元の『寂しさ』は失恋・喪失との関連が弱いと判断して削除し、『孤独』に変更。
- 出典：https://archive.artic.edu/seurat/seurat_themes.html

### 4. Claude Monet, Water Lilies（1906） / aic-16568
- **安心＝3**：水面に集中する構図と静かな鑑賞体験の観点から強めに設定。ただし鑑賞者の主観であり作者の確定意図ではない。
- **好奇心＝1**：変化する反射・光の観察への関心。
- **希望**：資料・図像との直接的つながりが薄いため削除。
- 出典：https://publications.artic.edu/node/135621
