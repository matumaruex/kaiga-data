## 未完了（壊れているという意味ではない）

- **美術史・解釈**：人間の最終承認は必要条件から廃止した。原資料・AIによる裏付け確認は別途必要で、専門家解釈と制作背景が当初同文の146件は再調査対象とし、最初の15件は2件の再調査を含めて全件修正し、次の15件も分離修正。現在の同文は116件。
- **過去の内容監査のB・C分類**：作者の手紙・作品背景に関する5件の補足案、感情タグの根拠に関する3件の検討案が [250作品時点の内容監査](curation-audit-250-2026-10-20.md) に残っている。A分類の明確な誤り3件だけ今回修正。数合わせのタグ変更はしない。
- **作品の全体画像・色**：JPEGの整合・縮小比較だけでは画像と作品の一致、切り抜き、色再現や画像権利を証明できない。必要な照合はAIと出典資料で行い、未確認は保留する。その他のAIC画像の高解像度化も未実施。
- **通信の安定性**：外部美術館やCommonsのURLは将来変更・速度低下する可能性があり、過去のSHA検証だけで将来の可用性は保証できない。
- **展示・選定品質**：アプリのコード試験と、実利用者の鑑賞体験やAI選定の妥当性の検証は別物。

## 変更時に守る運用

1. 登録作品数や作者IDを変更するときは、正本 `data/artworks.json` と画像台帳 `data/image-sources.json` を同じまとまった変更として更新する。途中で止まった場合はコミット時点に戻せるよう残す。
2. `check-artworks.yml` の `validate-format` が成功した状態だけを受け入れる。新しい300作品ベースラインの変更は意図的に行う。
3. アプリ側は `npm run catalog:sync` → `npm run typecheck` → `npm test` → `npm run build` を通す。DBのハッシュ付き画像参照はデータと同じ改訂で更新する。
4. 古い制作履歴は「以前の時点」と明示して残す。未確認の資料・画像を自動的に検証済みにしない。詳細は [現行レビュー手順](review-guide.md) を参照。
