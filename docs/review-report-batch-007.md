## 次の確認を完了するまで登録しない

1. The Metの作品APIで`objectID`、`accessionNumber`、`isPublicDomain`、`classification`、`primaryImage`を現行データと照合し、作品単位の画像を特定する。米国絵画『隠者』は作品ページに`Classification`欄が見当たらないが、油彩キャンバス作品と表示される。
2. 作者の異なる画賛・物語と、**作者自身が描いた目的**を混同しない。強く推せるのは小林清親の「題材としての怒り」、童鈺の自筆詩、サージェントの書簡、顧洛の着想源など。歴史的事件の感情を作者の実人生へ投影しない。
3. 二曲・六曲屏風、巻物、双面の絵を**作品IDの図版と一致**させ、実画像を取得して形式・バイト数・SHA256を記録する。URLだけで合格にしない。
4. 登録形式がシカゴ美術館のUUID画像IDと`aic-`接頭辞に結び付いているため、The MetのIDと画像を安全に扱えるよう**美術館共通スキーマと検査**を整えてから移行する。登録済みの51件を壊さない。
5. アフリカ、南北アメリカ、他のアジア地域、非宗教的な怒り・期待・喜びも後続の調査対象。今回だけで世界の偏りが解消したとは言わない。
