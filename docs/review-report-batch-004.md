## 評価の基本
- 意図と解釈は別。作者の人生に苦労があったからといって、作品がその苦労を表していると断定しない。
- 「ゴッホ『酒を飲む人々』」はドーミエの風刺からの翻案で、陽気な酒席だと決めつけない。
- 「ルノワールの曲芸師」は明るいサーカスの場面と、実在の働く少女たちの人物像を併せて読む。
- 「ゴーギャン『神の日』」はパリで制作したタヒチの神話的表現。描かれた宗教儀礼をそのまま現地文化の忠実な記録と説明しない。
- 「モネの積みわら」2点は色彩・時間の探究を別条件で比較できるもの。ただし1回の展示で似た2点を同時に出す義務はない。
- 「ゴヤ『エル・マラガト』」は銃による脅迫を描くため、推薦する際には注意が必要。
- 登録は画像のHTTP、JPEG、公式記録、ハッシュ等の**機械的検証を終えたという意味**。全画面を人が鑑賞したことや、作者の意図の完全な証明を意味しない。
- 外部画像の利用条件はCommonsの「public domain」を保存。配布開始前の法的確認は別途行う。
