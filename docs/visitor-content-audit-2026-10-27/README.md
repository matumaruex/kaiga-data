## 初回文章監査の方針

5件×20組で固定した台帳です。対象本文の版とSHA-256は[manifest.json](manifest.json)、現在位置は[progress.json](progress.json)にあります。再開時はprogressのnext_batchを読み、その組の5件から始めます。既に結果がある組を数え直したり上書きしたりしません。対象本文のハッシュが変わった場合は、その作品の再監査を別途記録します。

監査は作品同定、本文の主張と原資料の対応、作者証言・研究者の解釈・史実・伝承の区別、重要情報の欠落、自然な日本語を点検します。各組のJSONに根拠URL・該当箇所・問題点・修正案を保存します。

判定はno_text_issue_found（今回の文章照合で明確な問題なし）、needs_revision（本文の修正が必要）、needs_more_evidence（追加資料なしでは判定できない）の三種です。任意の改善提案はrecommendationとして区別します。すべて執筆者による再点検で、独立した第三者監査ではありません。

下書き本文・本番DB・承認台帳は変更せず、verifiedへの昇格や承認・マージも行いません。画像の独立照合と権利確認は、文章照合の判定とは別に記録します。共通の画像未確認を、毎件の事実誤認として数えません。
