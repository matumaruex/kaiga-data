# 1作品の検証済み版を保存する（2026-10-30）

[共通運用v2](artwork-completion-workflow-v2.md)に従う最初の登録経路。既存300作品のうち、鑑賞本文が未登録で、本文下書きと選定資料の限定修正案を検証した作品を1件ずつ正式DBへ保存する。人間の作品別承認は要求しない。

```sh
python3 scripts/complete_artwork.py preview --audit docs/artwork-completion-audits/met-435997-2026-10-30.json
python3 scripts/complete_artwork.py save --audit docs/artwork-completion-audits/met-435997-2026-10-30.json
python3 scripts/complete_artwork.py check
```

`preview`は書き込みなし。`save`は1作品だけを検証し、`data/artworks.json`を原子的に置換する。保存後はGit差分・CIを確認してmainへ統合する。すでに保存された作品は`check`で検証し、二重登録しない。

## 検証の責任

AIは原資料の該当箇所と画像を直接確認し、制作とは別工程で再参照する。史実・解釈・感情との接点・本文類似・利用条件の判断を監査JSONに残す。同じAIによる別工程を用いた場合は、その方法と限界を明記し、別担当の独立性を装わない。

プログラムはAIの判断を生成しない。PASSでも保留事項や登録不可が残る記録を拒否し、画像・下書き・修正案・元の作品の版を照合する。さらに一時コピー上で既存の構造・300作品スナップショット検査を実行し、対象外の作品を変更しない。画像の今回取得バイトが登録値に一致しないケースは、この最初の登録経路では受け付けない。

`rights_check.result=PASS`は、対象版の本文・画像にDB保存を妨げる重大な未解消事項を認めなかったというレビュー判断。画像のPublic Domainを文章に拡張せず、法的な非侵害保証や個別許諾の取得とは扱わない。

## 互換性と証拠の保存

本文と既存レビュー欄は検証した下書きのまま保存する。過去のpendingや人間承認台帳を偽の承認で埋めない。新しい`completion`欄は監査ファイルと正式DBの内容指紋を結び付ける。指紋から除くのは`completion`自身だけで、本文・出典・選定情報等が変われば検査は失敗する。作品の表示と選定に必要な従来のデータ構造は保持する。

`check`は、このcheckoutに保存された証拠に基づく完成・未完成・保留の件数を表示する。別ブランチだけにある保留記録は数えない。PR #3の過去の監査や下書きは削除せず、今回必要な対象作品の証拠だけを引き継ぐ。

この初期実装は、既存解説の置換、301件目以降の新規登録、異なる画像バイトの再照合には未対応で、入力を拒否する。新規下書きからの登録も同じ根拠条件を満たす必要がある。全300作品を完成済みとは扱わない。
