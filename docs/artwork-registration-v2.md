# 既存作品の完成登録方式（履歴案内）

この文書で以前説明していた `complete_artwork.py preview/save` は、初期300作品の完成登録に使った経路。現在の新規作品登録には使わない。

- **新規作品**： [新規作品の追加手順](artwork-expansion-v2.md) に従い、`scripts/add_artwork.py preview/save/check` を使う。
- **共通品質基準**： [作品の完成条件](artwork-completion-workflow-v2.md) を参照する。
- **既存作品の完成証拠**： `scripts/complete_artwork.py check` による検査は継続する。過去の監査・下書き・完了記録は変更しない。
- **旧方式の詳細**： [2026-11-10までの登録手順](history/artwork-registration-v2-through-2026-11-10.md) に保存した。旧「現行」や「優先」指示は当時の記録。
