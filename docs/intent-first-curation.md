# 制作意図を中心にするキュレーション方針（2026-10-18）

## 美術館の目的
利用者が自由に表現した感情を入口に、作者が何を表現しようとしたかに出会う。共感だけでなく、予想外の発見、第一印象と制作背景のずれ、作品への没入も価値とする。見た目だけで作者の心理を推定しない。

## 情報源の優先順位
1. 作者自身の言葉（手紙・日記など）。別作品や連作への言葉なら、その範囲を明記する。
2. 美術館の研究・信頼できる専門的解説。作者の明言と混同しない。
3. 制作当時の背景。作者の伝記と個別の作品を結ぶ根拠が必要。
4. 色彩・題材・構図は表現を理解するヒント。外見だけから制作意図を決めない。
5. それでも不明な意図は「確認できない」とする。感動的な物語で埋めない。

## 現在の51作品に用いる軽量構造
- `curation.meaning_basis.author_intent`：作者発言の状態と要約、出典。未確認なら本文も出典も `null`。
- `curation.meaning_basis.scholarly_interpretation`：専門家の読解とURL。
- `creation_context`：制作背景。
- `visual_clues`：画面と意味を結ぶ観察点。
- `uncertainty_note`：どこまで分かり、何は分からないか。
- `curation.emotion_categories.primary`：主要感情への入口を1～2個。
- `curation.emotion_categories.secondary`：弱い補助を0～2個。
- `curation.emotions`・`emotion_strengths`：従来方式との互換索引。主タグは強度2か3、補助は1。

感情タグは作者の感情の診断ではなく、利用者の自由な気持ちと歴史的な作品の意味を接続する検索索引。根拠と共感の強さを混同しない。

## 選定の設計（未実装）
一次検索は少数の主タグと短いAI用要約で候補を絞る。残った作品だけ詳細な制作意図・学術解釈を読み、利用者の文章との関係を判断する。
共鳴・対照・意外性を1作品に固定しない。同じ作品が相手によって違う役割を果たしうる。
「6作品中、共鳴4／違う向き合い方1／意外な出会い1」は実験上の仮説。無理に驚きを作らず、説明可能な関連のある作品だけを選ぶ。

## 今回確認できた作者本人の発言
- ゴッホ『寝室』：1888年の初版に関する「休息」の意図。シカゴの1889年第2版を直接説明する手紙と混同しない。[ゴッホ美術館](https://ontrafel.vangogh.nl/en/story/37/the-colour-has-to-do-the-job-here/)
- モネ『睡蓮』：水面の反射と変わりゆく光を重視する連作への言葉。1906年の1点に限定した直接声明ではない。[シカゴ美術館の研究](https://publications.artic.edu/api/epub/monet/135621/print_view)

当初18作品のうち、上記2件には「関連モチーフ・連作への本人の言葉」を記録した。その他16件は「当該作品への作者本人の直接発言は確認できない」と明記し、美術館・研究者の説明を別に記録した。「本人の意図が絶対に存在しない」という意味ではない。

## 品質管理
`scripts/validate_artworks.py` はタグの上限、本人発言の状態、出典URLと互換タグの整合を確認する。これは記述内容の美術史的正確性や展示の魅力を自動保証しない。人間による絵画史の判定を利用者に要求せず、作品の資料に基づく修正を積み重ねる。

本リポジトリの作品は現在51点。第6群では宗教・神話の主題を通して喪失感を補ったが、作者本人がその感情を込めた証拠は別に扱っている。怒りの主タグ0、寂しさの主タグ0は無理に埋めない。第5群ではピサロの『繕い物をする女性』『パリ、アーヴル広場』『コーヒーを飲む若い農婦』について本人の書簡が作品に言及している根拠を加え、ゴッホ『ラ・ベルスーズ』は関連する同題の作品群への作者の直接発言として区別。第4群の新10点は当該個別作品への作者自身の直接証言を確認できず、専門家の解釈と制作背景を根拠に整理している。第3群にはモネの海岸の連作に関する発言と、ムンクの一般的な芸術理念も加えた。ただし個別作品の直接声明ではない。1件の暴力的な題材は引き続き試験用本登録を保留。美術館アプリのプログラム自体は未変更。
