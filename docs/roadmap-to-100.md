# 絵画100作品までの収集計画（2026-10-18）

## 開始条件とゴール

**70作品が試験用登録済み（残り約30点）**。当面の目的は**100作品前後（目安95～105）を、根拠付きの品質で収集すること**。100点の作品がそろうまでは**実際の感情入力による展示選定の体験評価・最終展示アルゴリズムづくりに移らない**。自動検証のための固定テストは継続してよいが、これを展示体験の開始と混同しない。

「100点」は根拠がない作品を無理に増やすノルマではない。事実・画像・出典・感情の接続に未確認があれば、候補として保留し、正式な作品数に含めない。

## 作品1点ごとの品質基準

1. **作品の正確な同定**：美術館の作品ID、原題、作者、制作時期、絵画分類、公開条件と版の違いを確認。
2. **画像の一致と出典**：美術館の所蔵品番号とCommons等のファイルを照合し、JPEGの実取得・SHA256・配布条件を記録する。シカゴの公式IIIFが403の場合は別ソースを使う。
3. **作者の意図を優先**：本人の手紙や発言が個別作品に結び付くかを調査。関連作品の言葉なら、その範囲を明示。見つからなければ「不明」でよい。
4. **専門的な読解で補完**：美術館の学術カタログ・研究者などの出典URLを添えて、制作背景と作品の表現を説明。本人の意図にすり替えない。
5. **感情は検索用索引だけ**：主1～2タグ、補助0～2タグ。利用者が抱く感情と**作品の背景や意図の接点**を根拠として書く。見た目だけの推測・適当な象徴解釈は主タグにしない。
6. **反対の読み・不確かさ**：資料不足、異なる解釈、別版の混同、強い暴力・性的な主題などを明記。
7. **自動テスト**：タグ、作品ID、画像ハッシュ、出典、スキーマの整合を確認。テスト成功は美術史的真実の保証ではない。
