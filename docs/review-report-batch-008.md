# 第8群：感情・地域・表現の偏りを減らす作品調査（2026-10-18）

## 今回の結果

- **試験登録60作品→70作品（10作品追加）**。展示体験は100作品前後まで開始しない。
- The Metropolitan Museum of Artの個別作品解説から**16作品を候補**として調査。
- 現行公式[The Met Open Access API](https://metmuseum.github.io/)で作品ID・所蔵番号・題名・作者名（「伝」の違いを区別）・分類・PDフラグを照合し、**15/16件一致**。残る1件・川端龍子『小町屋敷』は**isPublicDomain=false**だったため登録不可。
- 公式APIの**primary JPEGを15/16件実取得**し、形式・サイズ・SHA256を保存。メタデータ一致の15件のうち10件を感情と展示上の判断を経て試験登録、残り5件は保留。
- [16件の検証JSON](batch008-online-result.json) ／ [第8群候補履歴](../data/candidates-batch-008.json) ／ [実検証コード](../scripts/research_batch008.py)。
- 新規の10作品は原画の主題と本人の発言、関連する文献・詩、専門家の解釈を区別。**目視による最終画像承認、意味の人間レビュー、公開前の法的確認は未実施**。

## 制作・管理の技術的補足

- 画像台帳は**71件**（試験登録70件＋旧来保留『Judith』1件）。追加10作品の`met-{objectID}`形式のID・画像URL・SHA256を記録。
- 登録レコードは現在の`data/artworks.json`で確認する。候補の`data/candidates-batch-008.json`には16件の履歴を残した。
- [第8群整合バリデーター](../scripts/validate_batch008.py)で、10登録・6保留・PD・画像ダイジェストを相互検証する。CIに常時チェックを追加。
- 費用・有料AI・展示選定アルゴリズムは未導入。100作品前後に揃えてから展示体験を評価する。
- 次群は地域を**中国・インド以外**にも広げ、まだ少ない**懐かしさ・希望・未練・喜び・期待**の質を高める。ただし文化圏のバランスのために根拠のない感情に振り替えない。
