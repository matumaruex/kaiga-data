# 鑑賞者向け解説の執筆・照合

現在の作品完成条件は [共通品質基準](artwork-completion-workflow-v2.md)、新規登録は [追加手順](artwork-expansion-v2.md) が正本。旧「10件ずつ提示して承認待ち」の方式は現在の必須手順ではない。

## 本文の品質

- 各作品に自然な日本語の**1種類の本文**を用意し、所蔵館の作品別解説や学術資料の**該当箇所**を確かめる。出典URLだけでは内容確認としない。
- 作者本人の発言、専門家の解釈、制作背景、画面の観察、未確認の推測を混同しない。重要な技法・制作変更・帰属上の留保などを資料に照らして取捨選択する。
- 資料にない人数・動作・心理を付け足さない。文章の独自性のために情報を水増ししない。公式解説の丸写しや逐語翻訳はしない。
- 文字数や結び方は固定せず、作品固有の内容に合わせる。曖昧で定型的な総括を繰り返さないが、自然な総括まで禁止しない。
- 本文と出典の検証、画像同定、文章・画像の権利確認を混同しない。制作とは別工程で確認した根拠と限界を作品別監査に残す。
