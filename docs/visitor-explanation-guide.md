# 鑑賞者向けの作品解説（2026-10-20、第1回）

## 目的・範囲
感情を入口に選ばれた作品を、鑑賞者自身の第一印象のあとでより深く理解できるように、作品ごとの一つの自然な日本語解説を用意する。解説の文章量は固定しない。共感・驚き・感動を誘導する作劇をしない。

本文は所蔵館の作品解説と学術資料を直接参照して執筆する。作者本人の発言・学芸員の読み・歴史的事実・鑑賞者が感じる可能性を区別する。専門資料の文章を転載・長文翻訳せず、日本語の独自表現で説明する。

## 保存形式
作品本体 `data/artworks.json` の各 `artworks[]` 要素の **トップレベル** に、必要な作品だけ次のオブジェクトを追加する。

```json
{
  "visitor_explanation": {
    "language": "ja",
    "text": "作品ごとに必要な長さで作成した解説本文",
    "source_urls": ["https://..."],
    "review": {
      "content_status": "verified",
      "source_status": "verified",
      "rights_status": "pending",
      "reviewed_on": "2026-10-20"
    }
  }
}
```

- `visitor_explanation` は **選定用ではない**。現行アプリの選定プロンプトと `curation.meaning_basis`、感情タグに自動転送・混合しない。
- 解説未作成作品はキーを持たない。空文章・仮本文を作らない。
- `language` は現在 `ja` のみ、`text` は完成した1種類の本文。段落は改行2つで分ける。
- `source_urls` は作品に即した一次・所蔵館公式・信頼できる専門出典を記録する。資料の存在だけでは内容確認にならない。
- `content_status` は本文各主張の正確性・確実性・読みやすさの編集検証。`source_status` は原資料の該当記述との照合。`rights_status` は文章の転載・翻訳・利用上の扱いを区別するための状態。`reviewed_on` はレビュー日（YYYY-MM-DD）。
- 各ステータスの語彙：`pending` / `verified` / `needs_revision`。不確かな状態を `verified` にしない。本文の `verified` には出典照合の `verified` が必要。
- `review.curatorial_review_status` など既存レビューは**別**。解説の検証完了を既存の全作品検証完了とは扱わない。

## 1件ごとの検証項目
1. 作品ID・題名・作者・制作年代と所蔵美術館の作品情報が一致。
2. 主な主張に実際の原資料・所蔵館公式・専門研究の根拠がある。URLだけでは合格にしない。
3. 画面から見た印象と、作者発言・研究者の読み・制作史を混同しない。未知の心理・人生は決めつけない。
4. 独立した日本語表現、わかりやすい文章、作品固有の深み、資料上の重要事項の欠落を確認する。
5. 他作品・複製・異版の取り違えとセンシティブな主題の説明を点検する。
6. 引用や画像の利用権は原資料の事実確認とは別に記録。未確認は `pending`。
7. データのキー一意性・URL・ステータス・非対象作品の不変性を機械検証する。
8. 5件単位で報告・承認された作品だけ収録する。
